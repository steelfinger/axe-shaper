Scope: Public marketing home at `/`, supporting trust pages, and first-run/help additions inside `/app`. Visitor mode is Persuade on public routes and Operate in the editor.

Audience/job/action: Hobbyist luthiers evaluating whether Axe Shaper can produce a buildable, true-scale body plan. They should understand the linked geometry promise, inspect a real output artifact, then open the free browser editor. A secondary audience can register interest in the native iPad app.

Proof/content: Lead with the app's own S-style `.axe.svg` output and its calibration square; explain linked scale, bridge, neck, and hardware math without unsupported claims. Use the real split guitar/axe mark as the identity signature, and credited documentary workshop photography to show the plan-to-wood handoff. Show web and iPad as sibling workbenches joined by the portable file format. GitHub is the public evidence for the open-source web app.

Direction: The printable plan is the hero and the page behaves like a blueprint drawer opened on a dark luthier's bench. A bright, measured sheet dominates the first viewport while compact bench labels explain why it can be trusted. The path is artifact → linked geometry → portable workflow → iPad interest → browser editor.

Constraints: Preserve the established Night Bench palette and editor behavior. Gold means current/truth, not decoration. Public pages must be responsive and indexable; the editor remains desktop-oriented. No fabricated customers, builds, release dates, or App Store availability. The initial iPad-interest action may use email until a list provider is configured. Public design permalinks/gallery are explicitly deferred to the sharing phase.
